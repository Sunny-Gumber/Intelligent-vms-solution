# VMS Complete Feature Master Checklist
### Vendor-neutral, Level 1 (Basic) → Level 5 (Best-in-Class AI/Command-Centre) + Extended Additions
*For product comparison, presales requirement gathering, tender preparation and competitive benchmarking (CP PLUS, Milestone XProtect, Genetec Security Center, Avigilon Unity/Alta, Nx Witness, HikCentral, DSS, etc.)*

> **Note:** No single VMS supports every item natively. Capabilities may be native, camera-dependent, integration-based, edition-restricted, cloud-only, or licence-gated. Always verify against current vendor documentation before including a claim in a tender or proposal.

## Maturity Levels

| Level | Classification | Typical deployment |
|---|---|---|
| **Level 1** | Basic VMS | Small office, shop, home, 4–32 cameras |
| **Level 2** | Professional VMS | School, warehouse, showroom, 32–256 cameras |
| **Level 3** | Advanced VMS | Factory, hospital, campus, 256–2,000 cameras |
| **Level 4** | Enterprise VMS | Airport, metro, government, large multi-site organization |
| **Level 5** | Best-in-Class AI VMS | Smart city, national infrastructure, advanced command centre |

## Final Note
Practical VMS capability depends heavily on configuration, client type, server architecture, security controls, device drivers, and the specific analytics package licensed — even where a feature is "supported," implementation details (dewarping, resolution limits, proprietary analytics dependencies) vary by vendor and firmware version. Every claim that goes into a tender or presales document should be tested and cross-referenced against current vendor documentation before submission.
